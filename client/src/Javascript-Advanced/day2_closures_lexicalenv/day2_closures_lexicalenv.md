Closure = A closure means a function remembers the variables of the place where it was created, even when that outer
          function has already completed execution. 

          1. Data Encapsulation = Data encapsulation means combining data and the functions that operate on that data while controlling how the data can be accessed or modified.
          2. Closure: A function bundled with its lexical environment.
          3. Lexical Scope: Function accesses variables based on where it is defined.
          4. Inner Function: Can access its own and outer function's variables.
          5. Outer Function Returns: Its execution context leaves the call stack, but the required lexical 
                environment remains accessible through the closure.
          6. Closure: Preserves access to outer variables between function calls.
